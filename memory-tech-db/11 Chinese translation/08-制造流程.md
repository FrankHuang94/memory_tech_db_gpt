# 08 制造流程

DRAM 的关键模块包括隔离、字线/接入晶体管、存储电容、位线与感测放大器、后段互连和晶圆测试。3D NAND 的难点是大堆叠沉积、深通道孔刻蚀、字线替换、阶梯接触、外围 CMOS 与阵列的集成。HBM 在晶圆良率之外还叠加 TSV、减薄、微凸块/键合、底填、基底裸片、中介层、封装测试和客户认证；堆叠放大会放大任一层的缺陷成本。

制造分析的第一原则是良率乘法：堆叠和封装会把单颗裸片的质量、测试覆盖和材料窗口共同转化为最终成品率。
