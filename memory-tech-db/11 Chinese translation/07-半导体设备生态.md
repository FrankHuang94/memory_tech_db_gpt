# 07 半导体设备生态

内存资本开支由产品复杂度和良率爬坡驱动，而非单看晶圆投片。DRAM、3D NAND 和 HBM 分别拉动光刻、刻蚀、沉积、清洗、量测、键合、基板、中介层、测试与材料。AI 封装把后道从传统成本中心变为系统级吞吐瓶颈；出口管制也使设备和材料供应链成为战略变量。

追踪 KPI 时，把设备订单拆成晶圆厂扩产、工艺迁移和先进封装三类；后两者常使单位晶圆的设备/测试内容增加。
