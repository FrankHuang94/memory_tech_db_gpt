# 项目说明、索引与来源

本库是面向半导体投资、供应链和先进封装读者的内存技术知识库。每篇原文力图同时回答：技术上改变了什么、哪些公司或产能使其商业化、瓶颈在哪里、以及数字和时间线依据何在。中文页是快速导航，不替代原始脚注。

| 原始文件 | 中文说明 |
|---|---|
| [README](../README.md) | 项目范围、文件结构、写作与研究方法、质量标准。 |
| [INDEX](../INDEX.md) | 全部计划文件、状态与篇幅控制表；适合查找主题。 |
| [PROGRESS](../PROGRESS.md) | 文件级更新日志和当前续写位置。 |
| [SOURCES](../SOURCES.md) | 去重后的主参考书目；所有数字应回到这里或原文脚注核验。 |

阅读原则：市场份额、价格、产品规格、产能和政策都具有时效性；先看原文发布日期和脚注，避免把研究机构的估计当作无归属事实。历史事实可引用旧资料，当前判断应优先采用公司、JEDEC、监管机构与近期一手来源。
