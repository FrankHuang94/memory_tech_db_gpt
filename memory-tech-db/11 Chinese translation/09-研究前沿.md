# 09 研究前沿

研究端正在并行推进 3D DRAM、垂直电容、HBM 热/封装协同、NAND-PIM、CXL 分层内存和混合键合。混合键合可降低互连间距与功耗，但对表面平整度、对准、洁净度、良率分析与 EDA 的要求很高。功耗和热已从封装级问题扩大到机柜、液冷、供电基础设施和全舰队可靠性问题；推理经济性最终常以每 token 能耗体现。
