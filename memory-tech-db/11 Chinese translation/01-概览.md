# 01 概览

内存层级的核心权衡是速度、容量、成本、功耗与持久性。SRAM 最快但昂贵；DRAM 是易失性工作内存；NAND 以高密度和低成本承担存储。浮栅与电荷俘获、SLC 至 PLC 的选择，决定密度、可靠性、ECC 与控制器负担。对设备公司而言，单元结构和堆叠复杂度决定刻蚀、沉积、量测及测试需求。
