# 02 历史

DRAM 从 SDRAM 经 DDR 到 DDR5，沿接口带宽、银行并行、供电和信号完整性不断演进；LPDDR偏向能效，GDDR服务图形，而 HBM 使封装本身成为产品定义的一部分。NAND 的关键转折是由平面缩放转向 3D 堆叠，并从 SLC 提高到 QLC/PLC 位密度；代价是更重的 ECC、控制器和可靠性管理。封装则从引线键合、倒装到 TSV、中介层、混合键合与 chiplet。

历史的结论是：几何缩放不再单独决定竞争力；封装互连、良率和控制器软件共同决定可售产品。
