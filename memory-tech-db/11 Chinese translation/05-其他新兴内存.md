# 05 其他新兴内存与近数据计算

CXL 为主机提供一致性连接的内存扩展与池化，改善容量利用率但要接受延迟和带宽折衷。MRAM、ReRAM、PCM 各有嵌入式或专用非易失性场景，尚非通用 DRAM 替代品。计算存储、CXL 近存计算和 HBM-PIM 的共同目标是减少数据搬运；真正障碍通常是软件、部署运维、认证和可证明的 TCO。Optane 的失败提醒业界：优秀物理性能本身不足以保证生态与成本闭环。
