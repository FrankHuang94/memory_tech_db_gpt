# 06 竞争格局

竞争不应只按 DRAM 或 NAND 份额排名。SK hynix 的 HBM 执行与封装能力、三星的规模和垂直整合、美光的美国制造选项与 HBM4 推进，分别构成不同的盈利与执行弹性。铠侠/SanDisk/WD 反映 NAND 合资与存储系统价值链；CXMT 和长江存储则需在出口管制、国产替代和设备可得性框架中分析。
