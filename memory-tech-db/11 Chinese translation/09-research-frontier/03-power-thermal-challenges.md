# 功耗与散热挑战

> [查看英文原文](../../09-research-frontier/03-power-thermal-challenges.md)

功耗和热行为已成为内存路线图的一阶约束。在 AI 系统中，内存既是热源，也是供电、封装平面图和数据中心冷却回路的一部分：HBM 紧邻千瓦级加速器，CXL 以链路功耗和延迟换取容量，NAND SSD 被拉入液冷 AI 存储托盘，先进封装又将热梯度变成可靠性和良率风险。不能在目标带宽下冷却的 TB 容量并非可用容量。

## HBM：接口处的热

HBM 的热量集中于 DRAM 核心、TSV/I/O 网络、基底裸片和与处理器相邻的 D2D PHY；后者正在成为热点。iHBM 类方案把冷却元件集成到 D2D PHY，Heat Path Block 类方案通过热柱把堆栈内部热量导向外部扩散器。HBM4 的每堆栈 TB/s 级带宽说明每代都必须提高带宽同时降低每比特焦耳数，不能无限增加堆栈功耗。客户认证会比较持续而非峰值速度：热更好的供应商即使标称速度略低，也可能因加速器维持 boost、避免内存降频而胜出。

## 封装与 EDA 余量

热量穿过逻辑裸片、HBM、插装层、基板、底填、热界面材料、扩散器和液冷板，传统板级模型难以充分表达这种耦合。热模型需结合封装 floorplan 与真实工作负载轨迹，决定电压/频率/热余量，并反馈电迁移、保持和封装应力风险。模型过于保守会导致过度冷却或降频；过于乐观则会带来现场节流和失效。内存厂商越来越需要提供热模型和表征数据，而不只是电气数据表。

## CXL 与容量层功耗

CXL 增加容量，也把功耗和延迟迁移到链路、交换机、retimer、控制器和远端设备。KV cache、嵌入表、稀疏参数或冷模型权重若可预测，可能容忍慢层；热激活路径和密集 attention 往往不能。CXL 容量若提升机架功耗、争用本地 DDR 带宽或制造尾延迟，会伤害 SLO。有效系统需把硬件与页迁移、压缩、预取、请求节流和准入控制结合，而非把所有远端容量视为等价资源。

## DRAM 刷新、漏电与热反馈

DRAM 功耗还包括激活/预充、刷新、漏电、终端、命令地址活动、低功耗状态和 PHY。温度升高会提高漏电、收紧保持分布，进而可能要求更保守刷新或更强错误管理；刷新又增加功耗，形成正反馈。HBM 靠近热加速器使该循环明显；服务器 DDR 在高容量高利用密集机架中也受影响。CXL 的不同设备和机架位置热状态不一，放置软件应考虑热降频和错误风险。

## 供电与基础设施

电力必须穿过电网、机架 PSU、板级 VRM/电源平面、封装基板和插装层到达逻辑与 HBM。电压下陷会迫使降频、增加余量或降低接口利用率，因此供电问题会转化为内存性能问题。先进内存产能还消耗晶圆厂、封装厂、测试楼层和数据中心的变压器、变电站、冷却水与测试电力；只统计晶圆开工会遗漏真正决定进度的基础设施长周期项。

## NAND、SSD 与存储冷却

AI 的检查点、检索语料、向量数据库、模型分片和日志使 SSD 进入靠近 GPU 的高密度机架。SSD 热问题不只来自 NAND：控制器、DRAM 缓存、PCIe PHY、VRM、风道和驱动器密度都重要。若 GPU 已液冷而存储仍依赖风扇，机架会形成效率低的混合冷却岛，增加功耗、维护复杂度与热循环风险；高容量企业 SSD 尤其需要在统一液冷路径中被评估。

## 液冷与工作负载稳定性

液冷不仅是设施选择，也是性能工具：稳定温度能保留 boost、减少余量、提高持续吞吐和每瓦性能。冷板与流道几何必须配合异构封装热图设计；随着 HBM、GPU、CPU 和交换 ASIC 共用封装/板卡，冷却成为系统架构的一部分。评估任何冷却主张时，应看真实负载下的温度分布、节流、功耗、长期可靠性和维护，而非只看空载或单点温度。

## PIM 与每 token 能耗

PIM 的核心动机是减少数据搬运能耗。长上下文推理会反复读取 KV 状态，若把热块在内存附近处理、冷数据放在高密度层，可降低每 token 数据移动和能耗并提升服务容量。但内存附近逻辑也耗面积、功率并增加设计和散热复杂度；有价值的 PIM 不是让每个存储位都昂贵计算化，而是证明端到端 token 吞吐、SLO 容量与能耗的改善。

## 可靠性与舰队运维

超大规模部署面对数千封装、机架位置、冷却回路、环境、固件和工作负载组合；同一 HBM 可能在训练、批推理、检索或多租户下经历不同热史。因此应细粒度采集温度、电流、节流、纠正/未纠正错误、SSD 与 CXL 热状态、冷却回路健康。遥测应驱动热点检测、放置、迁移和节流策略，并把 RMA/失效分析反馈给设计。目标是避免悬崖式行为：小热偏移应触发平滑迁移，而非静默错误、节点故障或机架级事件。

## KPI 观察清单

跟踪 HBM 堆栈功耗、热阻、D2D PHY 热点、真实冷却下持续带宽，以及 HBM5 冷却概念是否进入认证平台；跟踪 CXL 尾延迟、链路/交换机功耗及其对本地 DDR/HBM 的干扰；跟踪 SSD 功耗和 AI 存储是否默认液冷；同时比对封装热仿真与实测、余量释放和可靠性。内存效率不是单独的“瓦数”列，而是带宽、温度、机架电力、寿命和设施成本的耦合系统变量。
